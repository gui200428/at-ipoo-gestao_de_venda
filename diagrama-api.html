Tratamento de Erros

Funcionário não encontrado

Se a API retornar 404 Not Found, o sistema captura HttpClientErrorException.NotFound e lança RuntimeException com mensagem clara.

API de Funcionários indisponível

Se a conexão falhar (serviço offline), o sistema captura ResourceAccessException e retorna mensagem de indisponibilidade ao cliente.

Resposta nula da API

Se RestTemplate.getForObject() retornar null, o sistema lança exceção antes de tentar persistir a venda.

Resposta ao cliente

O VendaController retorna ResponseEntity com status 201 Created em sucesso, e lida com exceções para retornar 400/500.
